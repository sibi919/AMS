# Architecture

The existing Phase 1 portfolio is preserved in `src/sections`, `src/components` and `src/data`. React/Vite renders the public site and role-specific portal. Supabase Auth owns credentials. `profiles.role` and PostgreSQL row-level security authorize access; the role selector on the login page is only presentation. A private Edge Function creates Auth users after live permission checks, and a trigger creates profile and audit records in the same transaction.

The academic migration normalizes courses, batches, enrollments, lessons, Live sessions, discussions, private doubts, assignments, submissions, notes, notifications, watch sessions and credit. Admins control the catalogue and accounts; active Staff teach their assigned batches. Students read published material only after enrollment. Academic writes use `security definer` functions with explicit current-role and assignment checks. Public `anon` has no academic table access. Audit entries record account changes, content management, enrollment, marks and batch notifications. Private doubt access is tied to the Student's **current** Staff assignment; reassignment revokes the former Staff member's read access.

YouTube IDs are stored and rendered as embedded players. Staff/Admin explicitly publish lessons and Live sessions. Replays must be manually added as recorded lessons. Embedded YouTube cannot hide a video ID or provide DRM.

A Student starts a short-lived server watch session for a published enrolled lesson. Ordered heartbeats receive credit only if playback movement is plausible relative to server elapsed time; stored unique numeric intervals prevent replay credit, with one active session per student across lessons. Recording versions invalidate stale sessions, and videos with earned attendance cannot be replaced. Direct client writes to attendance credit and grades are denied. Attendance uses credited seconds divided by all published recorded-lesson seconds in the batch. Exact, unrounded percentages determine the 75% academy and 85% exam thresholds. The browser can simulate playback, so this is evidence of plausible playback rather than proof of a person's attention. Live watching does not count.
